# Student Management System in C

## About the Project
This is a Student Management System developed using the C programming language.

The project allows users to manage student records through a menu-driven program.

## Features
- Add new student records
- Display student details
- Search students by roll number
- Update student information
- Delete student records
- Exit the program

## Concepts Used
- Structures
- Functions
- Pointers
- Dynamic Memory Allocation
- Loops and Conditional Statements
- Switch Case

## Student Information
Each student record contains:
- Roll Number
- Name
- Marks

## How to Run
1. Download the C source file.
2. Open it in VS Code or any C compiler.
3. Compile the program using GCC:

```bash
gcc studentmanagementsystem.c -o studentmanagementsystem
```

4. Run the executable.
